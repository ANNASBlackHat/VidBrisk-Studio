# SPEC: Custom Audio Voiceover Upload UI & Integration — Frontend
**Project:** video-generation-frontend
**Status:** Draft
**Depends on / pairs with:** `SPEC_backend_custom_audio_upload.md`

## 1. Overview
Currently, the new job creation screen ([`src/app/jobs/new/page.tsx`](file:///Users/annasblackhat/Documents/Experiment/video-generation-frontend/src/app/jobs/new/page.tsx)) assumes all jobs use synthetic AI voiceovers generated by Kokoro TTS. This specification defines the frontend UI and API client updates to let users either generate AI voiceovers or upload their own pre-recorded voiceover audio file (`.mp3`, `.wav`, `.m4a`), with audio playback preview, duration check, and multipart job submission.

---

## 2. Current State (verified in codebase)
- `src/app/jobs/new/page.tsx` — provides script input, orientation selector (`horizontal`, `vertical`, `square`), and TTS voice picker (`af_heart`, `am_adam`, etc.). Submits JSON payload via `api.createJob(payload)`.
- `src/lib/api.ts::createJob` — sends `POST /jobs` with `Content-Type: application/json`.
- `src/lib/types.ts::JobCreateRequest` — defines `{ script?: string, prompt?: string, title?: string, voice_type?: string, target_orientation?: TargetOrientation }`.

---

## 3. Goals
- Add a **Voice Source Toggle** on the Job Creation page:
  - **Option 1: "AI Voice Generation"** (Kokoro TTS / voice persona dropdown).
  - **Option 2: "Upload Custom Voiceover"** (Drag-and-drop audio file uploader).
- Provide immediate audio preview playback (`<audio controls>`) and file metadata (duration, file size, format) upon upload.
- Update `api.createJob` to send `multipart/form-data` when an audio file is selected, or standard `application/json` when using synthetic TTS.
- Display custom audio badge on job summary and checkpoint review screens.

## Non-Goals
- Multi-track waveform audio editing in the creation modal (full trimming/editing is handled in the timeline editor).
- Direct in-browser microphone recording (can be added as a future enhancement).

## 5. API Client Updates (`src/lib/api.ts`)

Update `createJob` to support both JSON and `FormData`:

```typescript
export async function createJob(
  payload: JobCreateRequest,
  audioFile?: File | null
): Promise<JobResponse> {
  if (audioFile) {
    const formData = new FormData();
    if (payload.title) formData.append("title", payload.title);
    if (payload.script) formData.append("script", payload.script);
    if (payload.prompt) formData.append("prompt", payload.prompt);
    if (payload.target_orientation) formData.append("target_orientation", payload.target_orientation);
    formData.append("voice_type", "custom");
    formData.append("audio_file", audioFile);

    return request<JobResponse>("/jobs", {
      method: "POST",
      body: formData,
      // Note: omit Content-Type header so browser sets multipart boundary automatically
    });
  }

  return request<JobResponse>("/jobs", {
    method: "POST",
    body: JSON.stringify(payload),
  });
}
```

## 6. Success Criteria

1. **Seamless Mode Toggle**: User can switch between AI Voice Synthesis and Custom Audio Upload on the New Job page.
2. **Audio Verification**: User can listen to the uploaded audio file before submitting the job.
3. **Multipart Job Submission**: Submitting a job with an audio file creates the job in the backend without network or payload errors.
4. **Editor Alignment**: Sliced beats appear in the video editor timeline with word captions and sync matching the custom voiceover.
